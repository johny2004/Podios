# Podios

Una aplicación web sencilla para organizar competencias entre varias personas y ver quién va ganando en tiempo real.

## ¿Qué hace?

- Permite agregar jugadores de forma rápida.
- Registra los resultados de cada categoría o actividad.
- Suma puntos automáticamente según el orden en que termina cada jugador.
- Muestra un podio y una lista general con el puntaje actualizado.

## ¿Cómo funciona?

Primero agregas a los participantes, luego creas una categoría y ordenas a los jugadores según su resultado. Con eso, el sistema reparte los puntos y actualiza el podio al instante.

## Detalles útiles

- La información se conserva mientras la pestaña sigue abierta.
- Puedes borrar jugadores o categorías cuando ya no las necesites.
- También puedes reiniciar todo para empezar desde cero.
